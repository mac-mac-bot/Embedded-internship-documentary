## Key Competencies Developed
- **Core Hardware Foundations:** Datasheet interpretation, decoupling capacitor placement, pull-up/pull-down configurations, and voltage regulation analysis.
- **Processor Architectures:** Comparative analysis of Microcontrollers (MCU) vs. Microprocessors (MPU), memory mapping, and RISC vs. CISC architectures.
- **EDA & Schematic Design (KiCad):** Custom symbol creation, hierarchical sheets, net labeling, footprint assignment, and Electrical Rules Check (ERC) debugging.
- **PCB Reverse Engineering:** Physical trace inspection, SMD/through-hole component identification, multimeter continuity verification, and schematic reconstruction.
